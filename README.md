# ピンズコレクション管理アプリ

ポケモンのピンバッジコレクションを管理するWebアプリです。

## 管理できるもの

1. **ポケパーク 151** — ポケパーク カントーの151種ランダムピンバッジ。タップで所持数+1（ダブりも記録され、園内スタッフとの交換用に「ダブり」フィルタあり）
2. **ポケセン ロゴピンズ** — 国内16店舗＋海外2店舗（シンガポール・台北）のポケモンセンター ロゴピンズをプリセット。店舗や限定ピンの手動追加も可能
3. **その他** — ポケモンスリープ等、シリーズ外のバッジを自由に記録

## 写真の添付

各バッジの📷ボタンからスマホ／PCの写真を選ぶと、バッジ部分を正方形になぞって（ドラッグで位置調整・ピンチ/ホイールで拡大縮小）切り抜けます。保存されるのは切り抜き後の512×512 JPEG（1枚あたり数十KB）だけなので、元写真が重くても容量は増えません。200枚保存しても合計10MB程度です。

データの保存先: コレクション状態はlocalStorage、写真はIndexedDB（どちらもブラウザ内）。画面下部のバックアップ（写真込みJSON書き出し/読み込み）で機種変更にも対応できます。

## スマホから使う（GitHub Pages + PWA）

このアプリは GitHub Pages に公開して使えます（`main` に push すると GitHub Actions が自動デプロイ）。

- 公開URL: `https://<GitHubユーザー名>.github.io/pokepark-pins/`
- スマホのブラウザで開き「ホーム画面に追加」すると、アプリとして起動できます（PWA対応、オフラインでも閲覧・編集可）

### スマホ・PC間のデータ同期

画面下部の「同期設定」から、GitHubの**プライベートリポジトリ**をデータ置き場にした同期ができます。

1. GitHubで空のプライベートリポジトリを作る（例: `pokepark-pins-data`、READMEだけ入れて作成）
2. fine-grained PAT を作る: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
   - Repository access: **データ用リポジトリのみ**を選択
   - Permissions: **Contents: Read and write** のみ
   - 有効期限は最長（1年）にし、失効したら作り直して再設定する
3. アプリの「同期設定」でユーザー名・リポジトリ名・PATを入力して保存（PCとスマホの両方で同じ設定をする）

同期の動き: 起動時とアプリに戻った時にリモートの変更を取り込み、編集の30秒後に自動でアップロードします（「今すぐ同期」ボタンもあり）。写真も差分だけ同期されます。オフライン中の編集は次回オンライン時に反映されます。両方の端末で同時に編集した場合は、どちらを採用するか確認ダイアログが出ます（マージはされません）。

注意: PATが失効すると同期インジケータが赤くなり「要再設定」と表示されます（データは端末内に残るので消えません）。デプロイ直後に古い画面が表示された場合は、アプリを一度閉じて開き直すと更新されます。

### 同じWi-Fi内で試す場合（開発用）

```bash
npm run dev:host
```

を実行し、表示される `http://<PCのIPアドレス>:5173/pokepark-pins/` をスマホのブラウザで開きます。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173/pokepark-pins/ を開きます。

## ビルド（ホスティング用）

```bash
npm run build
```

`dist/` に静的ファイルが生成されます。GitHub PagesやNetlify等に置けばスマホからも使えます。
