# ピンズコレクション管理アプリ

ポケモンのピンバッジコレクションを管理するWebアプリです。

## 管理できるもの

1. **ポケパーク 151** — ポケパーク カントーの151種ランダムピンバッジ。タップで所持数+1（ダブりも記録され、園内スタッフとの交換用に「ダブり」フィルタあり）
2. **ポケセン ロゴピンズ** — 国内16店舗＋海外2店舗（シンガポール・台北）のポケモンセンター ロゴピンズをプリセット。店舗や限定ピンの手動追加も可能
3. **その他** — ポケモンスリープ等、シリーズ外のバッジを自由に記録

## 写真の添付

各バッジの📷ボタンからスマホ／PCの写真を選ぶと、バッジ部分を正方形になぞって（ドラッグで位置調整・ピンチ/ホイールで拡大縮小）切り抜けます。保存されるのは切り抜き後の512×512 JPEG（1枚あたり数十KB）だけなので、元写真が重くても容量は増えません。200枚保存しても合計10MB程度です。

データの保存先: コレクション状態はlocalStorage、写真はIndexedDB（どちらもブラウザ内）。画面下部のバックアップ（写真込みJSON書き出し/読み込み）で機種変更にも対応できます。

## スマホから使う

PCと同じWi-Fiにつないだスマホから使う場合:

```bash
npm run dev:host
```

を実行し、表示される `http://<PCのIPアドレス>:5173` をスマホのブラウザで開きます。
※データは端末ごとに保存されるため、PCとスマホで共有したい場合はバックアップJSONで受け渡してください。常時スマホで使うならビルドしてホスティングするのがおすすめです。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます。

## ビルド（ホスティング用）

```bash
npm run build
```

`dist/` に静的ファイルが生成されます。GitHub PagesやNetlify等に置けばスマホからも使えます。
